📱 SmartCalc: Advanced Scientific Calculator

SmartCalc হলো একটি অল-ইন-ওয়ান সায়েন্টিফিক ক্যালকুলেটর অ্যাপ, যা সাধারণ হিসাব-নিকাশ থেকে শুরু করে অ্যাডভান্সড ম্যাথমেটিক্স, ম্যাট্রিক্স, সমীকরণ সমাধান এবং ফাংশন গ্রাফ পর্যন্ত সবকিছু একটি মডার্ন এবং ক্লিন ইন্টারফেসে সম্পন্ন করতে পারে। এটি সম্পূর্ণরূপে Java এবং Android Studio দিয়ে তৈরি।
🚀 Key Features (প্রধান ফিচারসমূহ)
১. Scientific Calculator (সায়েন্টিফিক ক্যালকুলেটর)

    Basic Math: যোগ, বিয়োগ, গুণ, ভাগ, শতাংশ (%)।

    Advanced Math: ট্রিগনোমেট্রি (sin, cos, tan, asin, acos, atan), হাইপারবোলিক ফাংশন, লগারিদম (ln, log, log₂), পাওয়ার (x², xʸ), রুট (√, ∛), ফ্যাক্টোরিয়াল (!)।

    DEG/RAD Mode: ডিগ্রি এবং রেডিয়ান মধ্যে সুইচ করার সুবিধা।

    Memory Functions: MC (Memory Clear), MR (Memory Recall), M+ (Memory Add)।

    History: আগের হিসাবগুলো দেখার এবং পুনরায় ব্যবহার করার সুবিধা।

    Live Preview: টাইপ করার সময়ই নিচে লাইভ রেজাল্ট দেখা যায়।

    Custom Math Parser: কোনো থার্ড-পার্টি লাইব্রেরি ছাড়াই নিজস্ব Recursive Descent Parser দিয়ে জটিল এক্সপ্রেশন মূল্যায়ন করা হয়।

২. Unit Converter (ইউনিট কনভার্টার)

    ১০টি ক্যাটাগরি: Length (দৈর্ঘ্য), Mass (ভর), Area (ক্ষেত্রফল), Volume (আয়তন), Speed (গতি), Time (সময়), Data (ডেটা), Energy (শক্তি), Pressure (চাপ), Temperature (তাপমাত্রা)।

    ৮০+ ইউনিট: প্রতিটি ক্যাটাগরিতে রিয়েল-টাইম রূপান্তর (Real-time Conversion)।

    Temperature Logic: সেলসিয়াস, ফারেনহাইট এবং কেলভিনের জন্য বিশেষ গাণিতিক ফর্মুলা।

৩. Matrix Calculator (ম্যাট্রিক্স ক্যালকুলেটর)

    সাইজ: ২×২, ৩×৩, এবং ৪×৪ ম্যাট্রিক্স।

    অপারেশন: যোগ (A+B), বিয়োগ (A−B), গুণ (A×B), নির্ণায়ক (Determinant), বিপরীত ম্যাট্রিক্স (Inverse - Gauss-Jordan Elimination), এবং ট্রান্সপোজ (Transpose)।

৪. Equation Solver (সমীকরণ সমাধান)

    Quadratic Equation: ax² + bx + c = 0 এর মূল (Roots), ডিসক্রিমিন্যান্ট (Δ) এবং ভার্টেক্স (Vertex) নির্ণয়। জটিল বা ইমাজিনারি সংখ্যার (Complex Numbers) সাপোর্ট।

    Linear Systems: ২×২ এবং ৩×৩ লিনিয়ার সমীকরণ (Cramer's Rule এর মাধ্যমে) সমাধান।

৫. Statistics Engine (পরিসংখ্যান)

    ডেটা সেট থেকে Mean (গড়), Median (মধ্যমা), Mode (প্রচুরক), Variance (ভেদাঙ্ক), Standard Deviation (পরিমাণ বিচ্যুতি), Q1, Q3, IQR, এবং Geometric/Harmonic Mean বের করা।

৬. Function Grapher (ফাংশন গ্রাফ)

    Interactive Graph: যেকোনো ফাংশন (যেমন: sin(x), x^2, 1/x) এর গ্রাফ আঁকা।

    Gesture Support: দুই আঙুল দিয়ে জুম (Pinch-to-zoom) এবং ড্র্যাগ করে গ্রাফ সরানো (Pan) যায়।

    Adaptive Grid: স্ক্রিনের জুম লেভেল অনুযায়ী গ্রিড লাইন অটোমেটিক এডজাস্ট হয়।
